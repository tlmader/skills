## Publishing instructions

1. Clone `https://github.com/tlmader/skills.wiki.git`.
2. Create one `.md` file per page, named exactly as listed above.
3. Source content from `README.md` and each skill's `SKILL.md` description.
4. Push to the wiki's default branch.
